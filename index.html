Computer Architecture · Team Build

8-Bit CPU from Scratch

A team-built 8-bit computer based on Ben Eater's bus architecture, wired module by module and carried over to an FPGA.

  • Clock built from 555 timers with adjustable speed, manual single-step and run/step switching
  • A and B registers on 74LS173s, driving a shared 8-bit bus through tri-state transceivers
  • RAM and memory address register, programmed by hand with DIP switches
  • Output register decoded by an EEPROM onto a four-digit seven-segment display
  • Control logic and microcode for the instruction set, debugged with a logic analyzer

Gaucho Rocket Project · Avionics

Hot-Fire Thermocouple DAQ Board

A KiCad board that reads combustion-chamber temperatures during hot-fire tests: four MAX31856 thermocouple converters feeding an STM32L496 on a single PCB.

  • Four K-type channels on one shared SPI bus, each with its own chip-select
  • Per-channel data-ready and fault lines, so the MCU knows when a reading is fresh or a probe has opened
  • Logs chamber temperatures to microSD so data survives the test
  • Prototyped on MAX31856 breakouts; now the onboarding task for new avionics members
